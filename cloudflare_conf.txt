Rule 1 — ranvir.tech zone
Redirects both ranvir.tech and www.ranvir.tech → www.numbersandreality.com

Open Redirect Rules for ranvir.tech
Click Create rule
Fill in:
Rule name: Redirect to www.numbersandreality.com
When incoming requests match: Wildcard pattern
Request URL: http*://*ranvir.tech/*
Then → Target URL: https://www.numbersandreality.com/${2}
Status code: 301
Preserve query string: ✅ Enabled
Click Deploy
